# Hi, I'm the head of NCSA 👋

I lead the **National Association of Corporate Secretaries (NCSA)** — a Russian professional association in the field of corporate governance. My day-to-day work mixes running the organization, organizing forums and conferences, running educational programs, and doing research — and I use AI agents to make all of it systematic.

## What I do

- **Corporate governance practice** — board support, shareholder meetings, corporate reporting, investor relations expertise.
- **Education** — a professional development program "Corporate Secretary" (140 academic hours, 30 expert practitioners).
- **Research & writing** — market research, analytical reports, and articles on governance, dividends, and regulation.
- **Events** — forums and conferences for the corporate secretariat community.

## AI-assisted projects


| Project                                | What it does                                                                                                                                                                                                                                                                             |
|----------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Education program promo automation** | Turns a product brief into a full campaign plan (funnel stages, 17 publications across 4 channels) plus ready-to-publish drafts per channel: Telegram, VK, e-mail, website. Posts are structured as weekly JSON files; illustrations get a quality-mark overlay via a PowerShell script. |
| **Research → article pipeline**      | Two-agent pipeline: a researcher agent collects sources and writes an analytical report, then a writer agent turns it into a publishable article.                                                                                                                                        |
| **Weekly project control agent**       | Compares project plans against actual files and produces a compact status report: done / overdue / at risk / needs my decision.                                                                                                                                                          |
| **SEO audit & web content**        | SEO audits of the program site (`nokc-training.ru`) and channel-specific content generation.                                                                                                                                                                                             |


## Toolbox

`LLM agents (Claude Code)` · `Markdown / JSON` · `PowerShell` · `Excel` · `SEO / SMM / e-mail marketing`

My approach: **no heavy infrastructure** — the workflow runs on plain files (Markdown, JSON, PNG) and one or two helper scripts, with LLM agents doing the heavy lifting. Easy to audit, easy to hand over.
