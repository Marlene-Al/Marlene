# smm e-mail marketing

## Когда использовать
Используй skill, когда нужно быстро привести одно сообщение в несколько готовых постов для разных площадок.

## Роль агента
Ты менеджер проекта, ответственный за продвижение проекта на площадках: Telegram @NOKC1, E-mail, сайт https://nokc.org.ru/, ВКонтакте

## Тематика
Мероприятия на тему корпоративного управления в России: форумы, конференции, вебинары, семинары, образовательные программы

## Аудитория
Корпоративные секретари и сотрудники аппарата, руководители департаментов корпоративного управления, члены советов директоров, руководители компаний, акционеры и инвесторы, внутренние и внешние аудиторы, председатели и члены комитетов советов директоров по внутреннему контролю и аудиту, комплаенс-директора, директора по связям с инвесторами, корпоративные юристы, консультанты в сфере корпоративного права и управления

## Рабочий процесс
1. Прочитай исходное сообщение и выдели 2-3 главных факта.
2. Коротко объясни, почему это событие важно для аудитории.
3. Подготовь четыре версии постов (для каждой площадки):
   - Telegram — развернутый пост с контекстом и предложением принять участие в событии, до 300 слов, используй эмодзи для акцентов, используй хэштеги по аналогии с примером;
   - ВКонтакте - развернутый пост с контекстом и предложением принять участие в событии, до 300 слов, используй эмодзи для акцентов;
   - E-mail — развернутое сообщение с более подробным контекстом и предложением принять участие в событии, до 150 слов;
   - Новость на сайт — максимально подробное сообщение с указанием всех фактов о событии, важности и всех преимуществ, до 400 слов.
4. Сохрани посты в папку posts в формате json.
5. Создай Image Prompt для генерации картинки для каждой площадк для модели генерации изображений. Промпт должен описывать конкретную сцену, узнаваемый мем-формат или визуальный образ по исходному сообщению. Результат записывается в поле `image_prompt` на верхнем уровне JSON.
6. Не выполняй действий за пределами подготовки контентного файла.
7. Не добавляй текст до или после json внутри файла.

## Промпт: кампания продвижения образовательной программы

Используй этот промпт, когда пользователь просит план-график и тексты постов для продвижения образовательной программы на длительный период.

**Задача:** Проведи кампанию продвижения образовательной программы ассоциации на площадках: Telegram @NOKC1, ВКонтакте, E-mail, сайт nokc.org.ru.

**Исходные данные:** `data/приглашение-на-ппк` и сайт программы https://nokc-training.ru/ — перед работой перечитай файл и сверь факты (название, даты, стоимость, выгоды). Ключевая аудитория — по разделу «Аудитория» этого скилла.

**Период:** 1 октября 2026 — 28 января 2027. Публикации раз в неделю на каждой площадке синхронно (~17 недель).

**Часть 1. План-график.** Таблица на весь период: № недели / дата публикации / площадка / тема (угол подачи) / стадия воронки / призыв к действию. Особенности:
- E-mail на этапе 1 — раз в 2 недели, на этапах 2–3 — еженедельно.
- Недели 1–8 января: посты готовятся заранее, отправка 9–11 января — пометить в плане.
- Финальная неделя (25–28 января) — last call: дедлайн оплаты до старта программы.
Сохрани в `reports/` в виде, готовом для копирования в Excel.

**Часть 2. Тексты.** На каждую неделю — 4 поста по правилам рабочего процесса (Telegram ≤300 слов, ВКонтакте ≤300, E-mail ≤150, сайт ≤400), один JSON на неделю в `posts/` (posts/ГГГГ-ММ-ДД-week-NN.json) + image_prompt на каждый пост. Генерация помесячно, а не одним файлом.

**Правила контента:**
1. Каждый пост уникален по содержанию — программа раскрывается с разных сторон по неделям: анонс, для кого, модули и темы, эксперты-практики, удостоверение гос. образца, подготовка к сертификату НОКС, формат и расписание, результат и выгоды, обучение сотрудников группой от компании, цена и цена для членов НОКС, ответы на вопросы, дедлайн, ограниченность мест.
2. Нарастающая воронка:
   - Этап 1 «Анонс» (октябрь) — информирование, знакомство с программой;
   - Этап 2 «Польза и доказательства» (ноябрь — середина декабря) — программа, эксперты, результаты, снятие возражений;
   - Этап 3 «Решение и оплата» (середина декабря — 28 января) — дедлайн оплаты, ограниченность мест, прямые призывы оплатить, last call.
3. Призыв к действию соответствует стадии: подробнее на сайте → зарегистрироваться → оплатить.
4. Стиль, тон, терминология, хэштеги — по общим правилам скилла.
5. Все материалы — черновики в `posts/` и `reports/`; публикация и рассылка — только после явного разрешения пользователя.

## Иллюстрации для постов (процесс)

Картинка к посту готовится в два шага (в сессии нет генератора изображений, генерирует руководитель):
1. Взять `image_prompt` из JSON недели, уточнить «Формат 16:9, 1280×720» (если площадка не требует иного). Логотип в промпт не включать — генераторы искажают логотипы.
2. Руководитель сохраняет сгенерированную базу в `tmp\`, затем агент накладывает знак качества (правый верхний угол, фон логотипа делается прозрачным):
   `powershell -ExecutionPolicy Bypass -File scripts\add-logo.ps1 -Base tmp\<файл> -Out posts\<имя-итогового-файла>.png`
   - Прозрачный логотип кэшируется в `tmp\logo-noks-transparent.png`.
   - Параметры: `-Size` (доля логотипа от ширины, по умолчанию 0.13), `-MarginX` (отступ, 0.025).
   - Внимание: скрипт содержит только ASCII — не редактировать с кириллицей внутри; логотип ищется как первый `*.jpg` в `data\`.

## Критерии качества
- Пиши на русском языке.
- Используй юридическую терминологию с уклоном в корпоративное право и корпоративное управление.
- Пиши все посты без хайпа, убедительным и уверенным тоном.
- Пост в Telegram пиши в стиле примера из раздела «Примеры», сдержанно, но живым языком — без канцелярита.
- После выполнения задачи должен быть файл в папке `posts`. В нём: метадата об источнике, Image Prompt для генерации картинки,
готовый контент для каждой площадки в нужном формате
